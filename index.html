Autonomous Vehicle Project

Autonomous Parking Robocar

Developed an autonomous navigation system for the UCSD Robocar platform using ROS2, LiDAR, camera sensing, and motor control.

Tools Used: ROS2, Python, Docker, LiDAR, OAK-D Camera, Jetson Nano, VESC Motor Controller

Objective Achieved: Integrated perception and vehicle control so the car could detect objects, respond to its environment, and perform autonomous driving behaviors.

Lane Following using ROS2

Built a lane-following system where the car stayed inside lane boundaries using camera-based color detection.

Tools Used: ROS2, Python, OpenCV, Jetson Nano, OAK-D Camera

Objective Achieved: Detected lane colors, filtered pixels, and blurred background objects so the vehicle could drive within the lane in real time.
