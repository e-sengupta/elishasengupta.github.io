Autonomous Parking Robocar

Developed an autonomous navigation system for the UCSD Robocar platform using ROS2, LiDAR, and computer vision.

The project used an LD06 LiDAR sensor, OAK-D camera, Jetson Nano, and VESC motor controller to perform cone detection, stop-line detection, and autonomous vehicle behavior control.

Technologies: ROS2, Python, Docker, LiDAR, OAK-D Camera, Jetson Nano
