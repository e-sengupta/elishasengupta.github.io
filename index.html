PID Control Line Following Robocar

Designed and built an autonomous line-following robot using an ESP32 microcontroller, PID control, custom hardware integration, and mechanical chassis design.

The robocar followed black-line obstacle paths including straight tracks, circular loops, and swirly curved paths by using calibrated photoresistor sensor readings and real-time PID motor control adjustments.

Tools Used: ESP32, Arduino IDE, PID Control, Soldering, Breadboarding, Onshape CAD, 3D Printing, Laser Cutting

Objective Achieved: Successfully designed and tuned a robocar capable of autonomously following multiple obstacle paths while maintaining stability and speed through PID control optimization.

Photoresistor Calibration System

Photoresistors were used to detect the difference between the white surface and the black line during calibration.

The sensors were tuned to achieve a strong delta value between black and white readings so the robot could reliably track the line during movement.

Potentiometer PID Tuning System

Potentiometers were integrated into the system to allow real-time adjustment of the robot’s speed and PID values.

This enabled tuning of the proportional (P), integral (I), and derivative (D) gains to optimize the robot’s performance on different obstacle paths.

Motor Driver Integration

Motor drivers were used to control wheel speed and direction based on the PID controller output and sensor feedback.

The system enabled smooth steering corrections and stable autonomous motion throughout the obstacle course.

Prototype Development

Built and tested an early-stage robocar prototype using breadboarding, temporary wiring, and rapid hardware iteration.

CAD Chassis Design

Designed the robocar chassis in Onshape before fabrication using laser cutting and 3D printed components.

The design optimized placement for the ESP32, sensors, wheels, motor drivers, and battery system.
